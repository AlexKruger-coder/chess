# CLAUDE.md

## Цель проекта
Браузерные шахматы для хакатона.
**Ключевая фишка:** Интерактивный разбор и анализ сыгранной партии с помощью шахматного движка Stockfish (оценка позиций, лучшие ходы, графики преимущества, выявление ошибок/зевков).

## Важные особенности API `react-chessboard` (v5.x)
> ⚠️ **Внимание:** В версии 5.x API компонента изменился по сравнению с v4:
1. **Проп `options`:** Все конфигурации передаются внутри единого объекта `options`, а не плоскими пропсами:
   ```tsx
   <Chessboard
     options={{
       position: fenString,
       boardOrientation: 'white', // или 'black'
       onPieceDrop: ({ piece, sourceSquare, targetSquare }) => {
         // targetSquare может быть null при броске мимо доски
         return true; // true — ход разрешен, false — вернуть фигуру назад
       },
     }}
   />
   ```
2. **Сигнатура `onPieceDrop`:** Принимает один объект параметров `({ piece, sourceSquare, targetSquare }: PieceDropHandlerArgs)` и возвращает `boolean`.
3. **Подсветка клеток:** Используется свойство `squareStyles: Record<string, React.CSSProperties>`.
4. **Стрелки:** `arrows: Array<{ startSquare: string; endSquare: string; color: string }>`.
5. **Ограничение перетаскивания:** `canDragPiece: ({ isSparePiece, piece, square }: PieceHandlerArgs) => boolean`.

## Архитектура и структура проекта
- `src/game/` — вся логика игры и шахматного состояния. Основной хук: `useGame` (управление состоянием партии, ходами, историей через `chess.js`).
- `src/ui/` — компоненты пользовательского интерфейса (доска, панели управления, история ходов, списки, таймеры, кнопки).
- `src/engine/` — взаимодействие с шахматным движком Stockfish (Web Worker, протокол UCI, оценка позиций, анализ ходов, расчет лучших линий).
- `src/test/` — тесты и конфигурация тестового окружения (Vitest).

---

## Правила разработки
1. **Никакой самописной логики шахматных правил:** Все правила, легальность ходов, рокировки, взятие на проходе, превращение пешек, шах, мат, ничья — **только через `chess.js`**.
2. **Разделение ответственности:**
   - Логика партии — строго в `src/game/`.
   - UI — строго в `src/ui/`.
   - Движок Stockfish — строго в `src/engine/`.
3. **Обязательная проверка качества:** После выполнения каждой задачи необходимо запускать и проверять успешность выполнения:
   ```bash
   npm run build
   npm test
   ```
   Обе команды должны завершаться без ошибок (exit code 0).
